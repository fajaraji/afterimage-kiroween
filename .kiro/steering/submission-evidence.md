# Hackathon evidence mode

Use only when preparing public demo, repository, and Devpost submission. Audit `docs/HACKATHON.md`, `docs/DEMO.md`, and `docs/BUILD_LOG.md`. Describe **actual** Kiro usage (do not invent run traces, screenshots, credits, public URLs). Keep video under 3 minutes and make every claim match the deployed build.

**Costume Contest check:** confirm the video shows one run with primary read empty, a backup version holding the record, and a new primary read finding it again, each with a UTC read time and matching AWS evidence. Frankenstein evidence (spec 08) applies only if that category is reopened.
