# Competitive positioning and originality discipline

## What already exists
Privacy management vendors such as BigID, DataGrail and Transcend handle deletion requests and verification across systems. Public projects such as "Ghost Data Still Exists" overlap with evidence-based deletion checks. The frontend handoff also cites three reference projects (GhostTrace, Ghost Data Still Exists, Ghostinel) for ideas.

## What Afterimage shows
A small, fictional, replayable case in which an erased record returns from a retained backup, and each claim (primary empty, backup holds the record, primary read finds it again) rests on a separate read with a UTC time. It is a teaching demonstration, not a compliance tool. Avoid "first ever" and "only product" claims.
