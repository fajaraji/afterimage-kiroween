# Kiroween 2026 submission and compliance checklist
Authoritative source: https://kiroween.devpost.com/rules (re-check before submission). This file is a checklist, not legal advice.

- **Eligible period:** new project work created from Oct 30, 2026. Standard starter templates and libraries are allowed under the rules. Disclose other pre-existing code.
- **Deadline:** Dec 4, 2026 2:00 PM PST (Dec 5, 5:00 AM Asia/Jakarta). Plan to submit by Dec 3.
- **Category:** **Costume Contest** (ADR-0007). Select exactly one main category in Devpost. The Frankenstein plan is deferred and must not appear in claims.

## Checklist
- [ ] Working application URL that judges can open, working as shown in the video.
- [ ] Public GitHub repo URL with an open-source LICENSE visible on the home page.
- [ ] Root `.kiro/` committed and not excluded by any `.gitignore`.
- [ ] All source, assets, fixtures and run instructions committed.
- [ ] English description: problem, solution, features, audience, differentiation.
- [ ] Public YouTube demo **under 3 minutes** (target 2:45) showing the running app. Storyboard: `../../docs/backend-handoff.md` and `DEMO.md`.
- [ ] Truthful Kiro write-up: which specs, steering files, hooks and agents were actually used (only features really used).
- [ ] Disclose pre-existing work, external libraries and assets accurately.
- [ ] App usable without payment or private setup until the end of judging (Jan 29, 2027).
- [ ] Submission tested from a fresh browser with every URL checked.
- [ ] If bonus entries are chosen, satisfy their separate criteria.

## Costume Contest readiness
- [ ] The video shows, in one run, primary read empty, a backup version still holding the record, and a new primary read finding the restored record, each with a UTC read time.
- [ ] The app label says Connected (real AWS) or simulated, so viewers know which they see.
- [ ] Muted playback is understandable (English on-screen text).
- [ ] Accessibility basics hold: keyboard use, text status next to color, reduced motion.
- [ ] No claim of legal compliance, GDPR certification or universal erasure.
