# Security policy

This repository is a **synthetic-only training and testing laboratory**. It is not approved to connect to production databases or store personal information.

Report a vulnerability privately to the repository maintainer via GitHub's private vulnerability reporting feature after the public repository is configured; do not post exploitable details as a public issue.

Security expectations: no unbounded file paths, no arbitrary shell execution from scenario definitions, no production credentials, isolated sessions, scoped endpoints, and no real PII in public demo output. Read `docs/SECURITY-PRIVACY.md`.
